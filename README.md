# 听写与词汇练习工具

**SHENG-0615 × ChatGPT（OpenAI）共同创作。**

一个在本机运行的英语练习工具：支持英美音点读与连播、听写即时判题、错题复习，以及词汇学习、拼写和按词性填写释义。

听写与词汇各有独立错题库；词汇错题可筛选错题或少答、查看正确答案，并保留导入表格的加粗重点标记。兼容表格同步会显示实际写入的 List、轮次和单元格。

## 开始使用

1. 下载仓库 ZIP 并解压，用 Edge 或 Chrome 打开 `index.html`。
2. 点击“导入本地词库”，选择自己的词表，即可练习。
3. Windows 可选用 `开始练习.cmd` 接入自行提供的兼容 XLSX。

**不附带教材词库、题目、释义语料或个人练习记录。** 词库由使用者自行提供，导入内容和作答保存在本机。
