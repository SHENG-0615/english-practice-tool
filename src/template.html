语音与帮助

选择当前口音的声音，并检查设备是否已准备好。

缺少英音或没有声音怎么办？
  1. 先用 Microsoft Edge 或 Google Chrome 打开本文件，再点击“刷新语音”。
  2. Windows 中打开“设置 → 时间和语言 → 语音 → 添加语音”，添加英语（英国）或英语（美国）。
  3. 安装后完全退出并重新打开浏览器，再刷新语音列表。

打开 Windows 语音设置 微软官方说明

只使用实际标记为 en-GB 或 en-US 的声音。本地声音可离线使用；在线声音需要网络，声音是否自然取决于浏览器提供的语音。

如何开始练习？

本工具不附带词库或作答记录。先点“导入本地词库”，选择自己的 XLSX、CSV、TXT 或 JSON。词库及练习记录只保存在本机浏览器。

听写支持英美音、点读、连播、回车判分、错题库及手动标记不确定；词汇支持学习、看中文拼写及按词性填写中文释义。词性少答算对并提示缺漏。

兼容的完整工作簿可写回原列与汇总。普通词单仅在浏览器保存练习。若用 Windows 本机启动入口，两份兼容表需由使用者自行放入工具文件夹。
